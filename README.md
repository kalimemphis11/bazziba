# BAZZIBA

Anteprima Next.js del sito video. WordPress resta il backend. I file video restano su Bunny.

```bash
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000). La home, le categorie, la scheda video, i contest, la ricerca e i membri leggono i dati pubblici di bazziba.it.

Login, caricamento, voti e chat si collegano quando sarà installato il plugin headless. Fino ad allora quelle voci aprono le pagine attuali del sito.
