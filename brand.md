# BAZZIBA

Piattaforma video per contenuti artistici e culturali. Dark mode è il default.

## Palette

Stage light su fondo caldo, non nero puro.

| Token | Hex |
| --- | --- |
| background | `#141311` |
| foreground | `#f4f1ea` |
| elevated | `#221f1b` |

| line | `#3d3832` |
| accent | `#e7b15a` |

## Type

Geist Sans per l’interfaccia. Geist Mono con `tabular-nums` per durate, visualizzazioni e conteggi.

## Voice

Italiano. Diretto, da community artistica. Niente tono da software generico.
